# Blank / エマ / エンドフィールド 個人サイト

[简体中文](README.md) | **日本語** | [English](README.en.md)

[Yuimi-chaya の Blank テーマ](https://yuimi-chaya.github.io/themes/blank/)をもとに、独立したサイトとして構成した Astro 製の静的サイトです。Blank のモノクロの読みやすい画面に加え、エマの「桜色アーカイブ」と「エンドフィールド工業風」テーマを用意しています。3 つのテーマで記事、プロフィール、作品、コレクション、共通機能を共有します。

サイト：**[laozhej.github.io](https://laozhej.github.io/)** · 簡体字中国語・日本語・英語、ライト / ダークモードに対応。

## ローカルで実行

Node.js 22.12.0 以降が必要です。Node.js 24 を推奨します。

```sh
npm ci
npm run dev
```

ターミナルに表示されるローカル URL を開いてください。ビルドと成果物の確認：

```sh
npm run build
npm run preview
```

出力先は `dist/` です。静的サイトに対応したホスティングサービスにデプロイできます。

`Blank Space` は仮のサイト名です。サンプル記事は削除済みで、現在 `src/content/blog/` は空です。各ページは最初の正式な記事が公開されるまで空の状態を表示します。GitHub と Steam のプロフィールリンクは設定済みです。プロフィールのほかの項目は今後追記できます。架空の経歴は掲載していません。

中国語の原文記事を追加するには、`src/content/blog/` に Markdown ファイルを作成します。ファイル名が記事の URL になります（例：`first-post.md` → `/blog/first-post/`）。先頭に次のメタデータを記述します。

```yaml
---
title: 文章标题
description: 一句话摘要
pubDate: 2026-10-29
category: life   # tech、anime、life のいずれか
tags: [标签一, 标签二]
---
```

`draft: true` を指定した記事は公開されません。

## 主な機能

- ホーム、記事一覧、記事詳細、作品、ゲーム、プロフィール、404 ページ。
- タイトル・概要・タグの検索、カテゴリーの絞り込み、日付順の並べ替え、URL からの絞り込み状態の復元。
- 記事の目次、現在の見出しのハイライト、読書進捗、ページ先頭への移動。
- 右上の月 / 太陽ボタンによるライト / ダーク切り替え。手動で選ぶまでは OS の設定に追従し、選択後は現在のブラウザーに保存します。設定はページ、言語、共通モジュールを利用するテーマ間で共有されます。
- 簡体字中国語 / 日本語 / 英語の切り替え。記事の翻訳は `ja/`、`en/` サブディレクトリに置き、言語とライト / ダークの選択は独立して管理します。
- Blank / エマ / エンドフィールド工業風の切り替え。現在の言語、セクション、記事、クエリパラメーター、アンカーを維持します。テーマとライト / ダークの選択は独立しています。Blank の切り替えメニューは上部ナビゲーション、ほかのテーマは右下のパレットボタンにあります。
- プロフィールページとフッターの GitHub / Steam リンク、3 言語のクレジットとライセンスページ（`/credits/`）。
- サイト内のページ遷移はページ全体を再読み込みせず、ヘッダーを維持して本文をフェードで切り替えます。言語、テーマ、ライト / ダークの設定を保持し、ブラウザーの戻る / 進むではスクロール位置を復元します。
- 桜色アーカイブ（エマテーマ）のサイト名は「Arataki.br’s Base」、見出しフォントは Gloock です。ホームは Yuimi-chaya の Fuyukawa Kagari テーマを参考にしています。4 枚の素材を使った漫画風の背景、集中線、桜羽エマの立ち絵、ターミナル風のタイプ表示、毎日のお知らせ、スクロールに合わせて現れるプロフィール、訪問者のローカル時刻と落下するタグを表示する第 2 幕を備えています。セクションカードには『葬送のフリーレン』のモノクロ漫画の抜粋を 3 枚使用しています。
- エマテーマには舞い落ちる桜の花びら、ワイド画面のサイドスクロールマーカー、左下のフリーレン Live2D マスコットがあります。マスコットはビューポート幅 1000px 以上で表示され、視線がマウスを追い、クリックや再表示時に反応します。非表示の設定は現在のブラウザーに保存され、読み込みに失敗した場合は静止画を表示します。
- エマテーマの左側コンソールにある「桜色ラジオ」は、ブラウザーでリアルタイム合成するオリジナルのオルゴール曲を 3 曲収録しています。音声ファイルは読み込まず、エマのページ間では再生を継続し、別のテーマに移ると停止します。
- エンドフィールド工業風テーマは、紙とインクを思わせる配色、黄色のアクセント、角を切り落とした操作部品、等高線の背景、自前で配信する Saira フォントを使います。ゲームの UI 構成を参考にしており、ゲームの公式素材は使用していません。
- エマの各ページにはアニメーションの一時停止 / 再生ボタンがあります。一時停止中は全テーマでページ遷移アニメーションを省略します。OS の「視差効果を減らす」設定でも同様に省略し、ボタンを無効にします。
- デスクトップ・モバイルのレイアウト、キーボードフォーカス、本文へのスキップリンク、動きを減らす設定に対応。

## サイト共通の言語とテーマ

中国語は `/`、日本語は `/ja/`、英語は `/en/` を使用します。右上の言語切り替えは現在のセクションや記事を維持し、サイト共通の `site-locale` 設定を保存します。言語プレフィックスのない入口では保存済みの設定を使用しますが、明示的な `/ja/`、`/en/` リンクが優先されます。JavaScript が無効でも言語リンクを利用できます。

記事の中国語原文は `src/content/blog/`、翻訳は `ja/`、`en/` サブディレクトリに置きます。翻訳には `locale` と、中国語ファイル名に対応する `translationKey` を設定してください。記事リンクに言語プレフィックスを直接書き込まないでください。翻訳がない場合は、その旨を明示して中国語原文を表示します。翻訳を自動生成したり、翻訳済みとして扱ったりはしません。

言語処理は `src/core/i18n/` にあり、Blank から独立しています。新しいテーマも `getI18n()`、`getSiteContent()`、`LanguagePreference.astro`、`LanguageSwitcher.astro` を再利用し、3 言語のページを生成する必要があります。テーマのパスは `/ja/themes/new/blog/` のように言語プレフィックスの後に置き、テーマ変更時も現在の言語を保持します。この要件はプロジェクトの `AGENTS.md` にも記載されています。

プロフィール、プロジェクト、コレクション、ソーシャルリンクは同じ共通データを参照し、記事も共通の Markdown ソースを使います。編集して再デプロイすると、対応する全テーマに反映されます。同じ言語の内容を共有する仕組みであり、中国語の変更が日本語や英語に自動翻訳されるわけではありません。翻訳は別途更新してください。

検索、カテゴリーの絞り込み、日付順の並べ替え、読書進捗、ライト / ダークの処理は共通コアにあります。Blank はルートパス、エマは `/themes/ema/`、エンドフィールド工業風は `/themes/endfield/` を使用します。日本語・英語はその前に `/ja/`、`/en/` を付けます（例：`/ja/themes/endfield/`）。テーマメニューは現在のセクション、記事、言語、適用可能なクエリパラメーターとアンカーを維持します。選択は共通の `site-theme` 設定に保存されますが、実際のテーマは URL で決まります。保存済みの設定によって直接リンクやブラウザー履歴が強制的に書き換わることはありません。

各テーマはレイアウト、配色、インタラクションの見せ方を担当し、共通の属性を通じて同じ機能を利用します。テーマを追加する際は、[テーマ導入ガイド](docs/THEMES.md)に従ってデータ、機能、言語、ルーティングを接続してください。テーマ内に業務ロジックを複製しないでください。

共通の言語・設定・機能インターフェースの確認：`npm test`（Node.js 24 の TypeScript サポートを使用）。

## GitHub Pages へのデプロイ

公開リポジトリは `laozhej/laozhej.github.io` です。GitHub Actions でビルドとデプロイを行います。`main` にプッシュするたびに、Node.js 24 でロック済みの依存関係をインストールし、共通モジュールのテストと静的ページのビルドを実行して `dist/` を公開します。Actions から **Deploy to GitHub Pages** を手動実行することもできます。

リポジトリの **Settings → Pages → Build and deployment → Source** は **GitHub Actions** を使用します。デプロイ状況とログはリポジトリの Actions ページで確認できます。

ユーザーサイトの公開 URL はドメイン直下にあるため、`astro.config.mjs` では `site: "https://laozhej.github.io"` のみを設定し、リポジトリ名の `base` は設定しません。今後の更新は、このリポジトリの記事、データ、テーマのソースを直接編集できます。ChatGPT Sites は不要です。
