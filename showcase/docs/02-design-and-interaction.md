# 四套界面与交互

本页说明当前网站的四套主题实现（2026-11-28）。画廊中的 6 张 PNG 仍保留 2026-10-31 快照（Blank 与终末地早期版本），将在页头美术定稿后统一重拍；2026-11-06 已彻底移除芙莉莲 Live2D 看板娘与 PixiJS 依赖。

## Blank：把阅读放在前面

延续上游 Blank 的黑白与留白基础，中英文分别采用自托管的思源黑体（Noto Sans）与思源宋体（Noto Serif），标签与编号使用 JetBrains Mono。首页以大号站名、两行陈述、个人简介与三格内容入口开篇，随后是最新文章、常用工具与近况。

顶栏导航相对页面居中，主题切换器留在顶栏中方便直接切换。站内补充了首次打开入场、滚动浮现、标题下划线划出以及从深浅色按钮处圆形展开的视图过渡，在动效暂停或系统减少动态时全部静止。

## 艾玛「樱色档案」：角色主导的个人手账

首页采用全屏高度的立绘舞台：艾玛五幕立绘作为前景主角，点击人物或使用右侧剧场卡可切换五种姿态并按需预取下一幕；背景为代码绘制的分镜与静物（笔记本、茶杯、窗光）以及左缘樱枝。向下滚轮可拉起站主资料卡，随后是横向章节导览轨、居中物理下落标签雨与本地时钟，以及最近文章区。

文字与内页特点：
- 正文采用自托管霞鹜文楷（繁中霞鹜文楷 TC，日文 Klee One，英文页正文用 Nunito 且中文回落霞鹜文楷），标题与导航用 Noto Serif，拉丁展示字用 Gloock。
- 作品页采用编号展板与无裁切截图接触条；游戏页采用带类型色调与筛选条的游戏柜布局（手机端切为紧凑横排卡）；关于页为资料卡、来访信笺与收藏书架。
- 左侧（窄屏收进页脚）提供「艾玛控制台」：内置「樱色电台」循环播放三首本地 MP3（点击播放后才加载，在樱色档案内换页时保留曲目、进度与音量），首页与游戏页另提供「光标光圈」开关。
- 「樱色便笺」目前按站主要求暂时下架（`sakuraNotesEnabled = false`），便笺数据与原生 `<dialog closedby="any">` 实现保留在代码中。

## 终末地工业风：工业手册与机械反馈

以中性纸色、墨色与单一亮黄（`#FFFA00`）构成手册视觉，可按控件右下角切角、圆角一律为 0，配合等高线底纹与自托管 Saira 宽体拉丁字、Noto Sans 中日文。首页包含统计字段、实心加空心描边站名、斜线阴影的最新文章画框、编号索引、工具看板与近况条。

交互动效围绕“短促、对应具体操作”设计：首次加载数字跳动定格、鼠标悬停/聚焦时的强调色擦入、首页画框轻视差、主题内换页斜边揭开，以及深浅色圆形展开。除首页外，其余栏目复用 Blank 页面结构并由终末地样式重绘。

## 明日方舟：档案终端

2026-11-26 新增的第四套主题（PR #43），独立设计且不使用任何游戏官方素材。深色模式为运行中的档案终端，浅色模式为打印档案纸，以单一青色作为信号色；拉丁栏目标题与大号编号采用自托管 Oswald，技术标注用 JetBrains Mono，中日文用 Noto Sans。

首页按五个区段编号排列：标题块与展示最新文章编号的点阵牌、文章日志、工具术语表、四个竖条喜欢的游戏面板，以及近况栏。右侧固定状态轨随滚动更新区段计数，并利用 CSS `animation-timeline: scroll()` 显示阅读进度；切换深浅色时采用自上而下的扫描过渡。

## 共用的交互与无障碍约定

- **语言跨主题共享。** 四种语言在公共层维护，切换语言保留当前主题、页面与查询参数；无前缀访问会按浏览器语言自动匹配。
- **深浅色可回到跟随系统。** 首次跟随系统；每次点击切到另一种模式，若切回系统当前模式则清除保存的覆盖项，重新跟随系统（不另设第三按钮）。
- **主题切换入口统一。** Blank 保留在顶栏；其余三套主题使用右下角无文字调色板按钮，展开带编号的四主题列表（Ema 在窄屏收进顶栏设置菜单）。
- **动效控制与平滑回顶。** 全站共享动效暂停状态与系统减少动态检测；四套主题页脚的「回到顶部」均支持平滑滚动，暂停动效时改为即时跳转。
- **触控目标与读屏友好。** 四套主题的可点控件均扩展至至少 44 px；控件可访问名称包含可见文字（WCAG 2.5.3），同页导航区域名称互不重复，压图/半透明背景文字均做过逐像素对比度核查。
- **宽屏有约束地放大。** 超过 1600 px 时按视口宽高同比放大，上限 1.5 倍，防止短屏内容溢出。
