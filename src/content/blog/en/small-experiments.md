> This is a sample making journal, showing how longer text, lists, and code blocks look on the page.

## Give it a form first

A vague idea becomes easier to develop once it is something you can see and try.

Start with the smallest part: a page, a paragraph, a button that responds. Then look back and decide what is worth keeping.

## Record an attempt

A simple note can cover three things:

1. **What you want to do**: Describe the experiment in one sentence.
2. **What you made**: Keep a screenshot, a short fragment, or a link to try it.
3. **What comes next**: Write down just one concrete, small step.

### A little code

Code can be just one fragment of the record, too.

```js
const journal = {
  title: "A small experiment",
  status: "Gradually taking shape",
};

console.log(journal.title);
```

## Change a little at a time

There is value in the process: what felt awkward, what turned out to be more interesting than expected, and which detail made the whole page feel better.

Write those things down, and you have a starting point for next time.
