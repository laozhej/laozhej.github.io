> これは制作ノートのサンプルです。長めの文章、リスト、コードブロックの読み心地を確認するために用意しています。

## まずは形にする

ぼんやりとした考えも、見たり試したりできるものにすると、次に何をすればよいかが分かりやすくなります。

最初につくるのは、小さな一部分で十分です。一枚のページ、一段落の文章、反応するボタンひとつ。そこから振り返って、残したいものを選んでいきます。

## 一度の試みを記録する

簡単な記録には、次の三つがあればよさそうです。

1. **何をしたいか**：今回の試みを一文で表す。
2. **何ができたか**：スクリーンショット、短い断片、または実際に試せる入口を残す。
3. **次に何をするか**：いちばん具体的な、小さな一歩だけを書く。

### 短いコード

コードも、記録の中のひとつの断片で構いません。

```js
const journal = {
  title: "小さな実験",
  status: "少しずつ改善中",
};

console.log(journal.title);
```

## 一度に少しずつ

試みることの価値は、その過程にもあります。どこが使いにくかったか、何が予想以上に面白かったか、どんな細部でページ全体が心地よくなったか。

それを書き留めておけば、次の出発点になります。
